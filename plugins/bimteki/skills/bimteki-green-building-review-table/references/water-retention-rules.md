# 綠建築基準——基地保水檢討規則整理

法源：建築技術規則建築設計施工編（下稱本編）第 298、299、305、306、307 條＋
「建築基地保水設計技術規範」（內政部 108.12.19 台內營字第 1080822863 號令修正，下稱保水規範）。
本檔為 108.12.19 版之整理；引用前若距整理日（2026-08）已久，先確認規範未再修正。

## 1. 適用把關（本編 §298 第 2 款）

適用：**新建建築物**。免檢討：

| 免檢討情形 | 備註 |
|---|---|
| 本編第十三章山坡地建築 | 已依水土保持技術規範規劃設計者 |
| 地下水位小於 1 公尺之建築基地 | 多孔地質鑽探資料中**任一孔**地下水位＜1m 即屬之 |
| 個別興建農舍 | |
| 基地面積 300 m² 以下 | |

另依 §306：檢討以**一宗基地**為原則；局部新建執照得整宗綜合檢討或依合理分割範圍單獨檢討（劃分原則同綠化）。

## 2. 評估基準（本編 §305＋保水規範 5.1）

```
合格判斷式： λ ＞ λc
λ  ＝ Q ÷ Q0          （開發後基地保水量 ÷ 原基地保水量）
Q  ＝ Σ Qi            （且 Q 不得大於 Q0；若大於 Q0，以 Q0 計）
Q0 ＝ A0 × f × t
λc ＝ 0.5 ×（1 − r）   （基地保水指標基準值）
```

| 變數 | 意義 | 認定方式 |
|---|---|---|
| λ | 基地保水指標（無單位） | |
| λc | 基準值 | 一般＝0.5×(1−r)；**學校校園整體評估採 0.5**（學校局部基地分割評估仍用 0.5×(1−r)） |
| A0 | 基地總面積（m²） | 申請建照一宗基地範圍 |
| r | 法定建蔽率 | **r＞0.85 令 r＝0.85**；分期分區局部評估用實際建蔽率（不得高於法定）；公共設施用地等「地下建築物」案一律用法定建蔽率 |
| f | 基地最終入滲率（m/s） | 現地入滲試驗，或以表層 2m 以內土壤認定：有鑽探資料→統一土壤分類查表 2；無→技師／建築師依土壤實況查表 3（免附鑽探資料）；**回填土統一取 10⁻⁵** |
| t | 最大降雨延時基準值 | **86,400 秒**（固定） |

## 3. 土壤最終入滲率 f（保水規範 表 2／表 3）

**表 2（有鑽探資料，依統一土壤分類）**：

| 統一土壤分類 | 土層描述 | f (m/s) | k 水力傳導係數 (m/s) |
|---|---|---|---|
| GP／GW／GM／GC | 礫石類（不良級配／良級配／沈泥質／黏土質） | 10⁻⁵ | GP:10⁻³；GW/GM/GC:10⁻⁴ |
| SP／SW | 不良級配砂／良級配砂 | 10⁻⁵ | 10⁻⁵ |
| SM／SC | 沈泥質砂／黏土質砂 | 10⁻⁶ | 10⁻⁷ |
| ML | 泥質黏土 | 10⁻⁷ | 10⁻⁸ |
| CL | 黏土 | 10⁻⁷ | 10⁻⁹ |
| CH | 高塑性黏土 | 10⁻⁷ | 10⁻¹¹ |

**表 3（無鑽探資料簡易對照）**：砂土 f=10⁻⁵（k=10⁻⁵）／粉土 f=10⁻⁶（k=10⁻⁷）／黏土 f=10⁻⁷（k=10⁻⁹）／高塑性黏土 f 同黏土欄（k=10⁻¹¹）。

k 值用於判斷設計手法適用性（k≧10⁻⁷ 適合直接滲透設計 Q1/Q2/Q4/Q6~Q8；k＜10⁻⁷ 適合貯集設計 Q3/Q4/Q5）；**保水量公式計算用的是 f**。

## 4. 各類保水設計之保水量 Qi（保水規範 表 1）

| 項目 | 保水設計 | 公式 | 變數與限制 |
|---|---|---|---|
| **常用** Q1 | 綠地、被覆地、草溝 | `Q1 = A1·f·t` | A1＝面積（m²），草溝可算入立體周邊面積。**限地下無人造構造物、其上無人工鋪面之自然土地**——下有地下室之地面層花園歸 Q3；下有地下室之無植栽裸露地（如球場）**完全不計** |
| **常用** Q2 | 透水鋪面 | 連鎖磚型 `Q2 = 0.5·A2·f·t + 0.05·h·A2`；通氣管結構型 `Q2 = 0.5·A2·f·t + 0.3·h·A2` | A2＝面積；h＝基層級配厚度（m）**≦0.25**；基層為混凝土等不透水面則 Q2=0；表層實體塊材每塊 ≦0.25m²（植草磚不限）且乾砌；鋪面下須 1m 以上土壤；透水混凝土／瀝青不得計入基層厚度 |
| **常用** Q3 | 人工地盤花園土壤貯集 | `Q3 = 0.05·V3` | V3＝花園土壤設施總體積（m³），**最多計入深度 0.6m 以內** |
| 特殊 Q4 | 貯集滲透空地或景觀貯集滲透池 | `Q4 = 0.36·A4·f·t + V4` | A4＝可透水面積；V4＝可貯集體積（高低水位間體積）。公共安全：k≧10⁻⁷ 時蓄水深度 小學≦20cm／中學≦30cm／一般≦50cm，邊緣高差分段漸變 |
| 特殊 Q5 | 地下貯集滲透設施 | `Q5 = 0.36·A5·f·t + r·V5` | A5＝可透水區域**總側表面積**（底面不計）；r＝孔隙率（礫石 0.2、組合式蓄水框架 0.9，有證明可從其證明）；V5＝蓄水空間體積，礫石貯集**最多計入地表深度 1m 以內** |
| 特殊 Q6 | 滲透（排水）管 | `Q6 = 2.88·x^0.2·f·L6·t + 0.1·L6` | L6＝總長度（m）；x＝開孔率（開孔面積/表面積，小數） |
| 特殊 Q7 | 滲透陰井 | 獨立 `Q7 = 1.08·f·n·t + 0.015·n`；搭配滲透管/側溝 `Q7 = 0.54·f·n·t + 0.015·n` | n＝個數；井間距 ≧1.5m |
| 特殊 Q8 | 滲透側溝 | `Q8 = 0.36·a·f·L8·t + 0.1·L8` | L8＝總長度（m）；a＝材質係數（透水磚／透水混凝土 18.0、紅磚 15.0）；不臨接牆面／擋土牆（距離＞70cm） |

Q6~Q8 以規範標準尺寸設施為計算依據，實際尺寸差異過大須另行認定。Q4~Q8 各設施間距須 ≧4.0m（Q7 除外另有 1.5m 規定）。

## 5. 設計注意事項（保水規範 7 摘要）

1. Q1~Q3 為一般常用保水設計，適用任何基地；Q4~Q8 為特殊排水滲透工程，**有水土保持危害之虞**：擋土牆、重要構造物、道路周圍須保持安全距離；山坡地及地盤滑動危險區**嚴禁採用**；遇 30 度以上駁崁須距其高差二倍以外。
2. Q6~Q8 透水管路須在**無雨水污染、雨污水嚴格分流**下始得採用（臺灣現況常有雜排水混入，規範建議勿輕易嘗試）。
3. Q4~Q8 公式皆為「直接滲透項＋空間貯集項」兩部分。
4. f、k 之認定見第 3 節；多孔鑽探資料不一致時由技師／建築師依分布取代表值。

## 6. 附件一「基地保水評估總表」結構——建表版式依據

- 一、建築物基本資料：建築名稱／基地面積／總樓地板面積／法定建蔽率。
- 二、基地最終入滲率 f 判斷：鑽探調查報告有無、土壤分類、k、f。
- 三、基地保水評估：常用（Q1~Q3）與特殊（Q4~Q8）保水設計逐列——欄位＝〔保水設計手法｜公式說明｜保水量 Qi〕，末列 ΣQi。
- 四、基地保水設計值計算：Q＝ΣQi、Q0＝A0·f·t、λ＝Q/Q0。
- 五、基準值 λc 計算：λc＝0.5×(1−r)（r 規則見第 2 節）。
- 六、合格標準檢討：λ＞λc？＋簽證人（姓名、開業證書字號、事務所名稱地址）簽章。

## 7. 計算實例（保水規範 8 摘要，可作 sanity check 樣本）

某國小新建工程，基地 7803.65 m²、法定建蔽率 50%，表層 2m 內為回填層 → f=10⁻⁵：
Q1＝2957.12×10⁻⁵×86400＝2554.95；Q2＝0.5×1411.27×10⁻⁵×86400＋0.05×0.25×1411.27＝627.3；
Q＝3182.25；Q0＝7803.68×10⁻⁵×86400＝6742.38；λ＝0.47＜λc＝0.5（學校校園整體評估）→ **不合格**（示範不合格情形）。
