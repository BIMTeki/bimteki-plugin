# 一鍵生成的六張表：內容說明（供回答使用者問題用）

版面與條件由外掛 `Generate_Area_Review_Tables`（`TJLtools27\Src\ReviewTableGen_*.cpp`）決定，這裡只摘要「會長什麼樣、哪些是條件顯示、哪些要人工填」。**以外掛實際輸出為準**，不要拿這份去「修正」外掛的結果。所有數值一律綁 autotext（token 由欄位鍵直接產生，不經 catalog 比對）。

所有樣板放在專案資料夾「容積檢討表 - 自動生成」子資料夾（外掛 v1.1.1 以前叫「容積檢討表」，重跑一次會自動改名），各自帶生成鍵（`generatorKey`）：重跑時依鍵找回同一份樣板原地更新（templateId 不變），已放置的表格同步重繪；複製、匯出、從檔案匯入的樣板不帶鍵，不受管。

## 案型與共同規則

- 案型來自專案設定：共用梯廳／單棟、非共用梯廳／單棟、共用梯廳／多棟分層、非共用梯廳／多棟分層、連棟透天分棟。連棟透天固定視為非共用梯廳。
- 判 0 容差 `abs(value) < 0.005`。
- 跳過條件（`skipped`）：容積區域為 0 → 面積總表／各層容積／地下層／屋突全部略過；建築面積區域為 0 → 建蔽率／基地概要略過；沒有地上層 → 各層容積略過；沒有屋突層 → 屋突略過；沒有地下層也沒有地下停車資料 → 地下層略過（MCP 明確點名 `basement_volume` 仍建）。

## 各層樓地板面積總表（`summary`，樣板名「各層樓地板面積」，全案一張）

- 欄：層別｜樓高｜樓地板面積(A)｜不計入容積(B) 群｜計入容積(C) 群｜容積樓地板面積(D)｜陽台面積｜用途。B／C 群子欄依**全案總計為 0 者移除**；非共用梯廳（含連棟透天）移除梯廳面積、陽台10%、梯廳10%、陽台+梯廳15% 四欄；一般多棟若各棟總計層沒有樓高資料則移除樓高欄；連棟透天最左多一欄「棟別」。
- 列：標題三列 → 騎樓列（全案騎樓面積 > 0 才有；地上一層的容積騎樓為 0 時改綁專案層級「面積：騎樓總樓地板面積」）→ 樓層列（單棟＝各層含夾層與小計；一般多棟＝各棟總計各層；連棟透天＝逐棟各層＋「Ｘ棟小計」＋全案「總　計」，棟別欄垂直合併）→ 總計列（A 欄綁「計算式：總樓地板面積」，含騎樓）→ 機電空間容積檢討列（安全梯和管委會空間或機電設備空間和管道間 > 0 才有）→ 地下層容積檢討列（地下層採總量檢討且地下層面積 > 0 才有）→ 最終容積樓地板面積列。
- 全欄等寬；用途欄 380、其餘 100、棟別欄 60。

## 各層容積檢討（`per_floor_volume`，樣板名「地上X層容積檢討」，每地上層一張）

- 四段：當層樓地板面積(A)／免計容積(B)／回計容積(C)／(A)-(B)+(C)。B 段各項 > 0 才列、梯廳另需共用梯廳；C 段 10%／15%／梯廳10%／陽台10%／陽台+梯廳15% 需共用梯廳且（梯廳 > 0 或陽台 > 0），停車回計需停車空間 > 0，裝飾柱回計需 > 0。工廠類建築（陽台全額計入）A 段只留室內／陽台／當層三列並拿掉陽台10%；陽台為 0 時拿掉陽台相關五列。
- 版面：單棟 single（段標籤｜項目｜值）；單棟＋夾層 mezz_single（項目｜當層｜夾層｜小計）；一般多棟 blockrows（室內／陽台／陽台>2m 逐棟列＋小計，其餘綁各棟總計）；一般多棟＋夾層 mezz（各棟欄＋小計欄，當層／夾層／小計三列）；連棟透天 columns（各棟並排成欄）；連棟透天＋夾層 mezzcolumns（各棟並排成欄、split 項目拆當層／夾層／小計三列，小計綁各棟自己的當層＋夾層小計層，沒有夾層的棟夾層格留空）。
- 各格已綁該層，放置時不必選樓層。

## 地下層容積檢討（`basement_volume`，樣板名「地下層容積檢討」，全案一張）

- 欄：樓層｜汽車位數｜機車位數｜（實設自行車位 > 0 時加自行車位數）｜樓地板面積(m²)。
- 列：標題 → 欄頭 → 陣列自動文字「地下層停車清單」（放置時逐樓層展開）→ 小計（綁地下層總計 token）→ 「檢討：」分隔 → 防空避難設備面積（綁法定防空避難室面積＋「m² (按建築面積附建)」）→ 可扣容積總計（算式）→ 檢討（地下室容積檢討式）。

## 屋突面積檢討（`rooftop`，樣板名「屋突X層面積檢討」，每屋突層一張）

- 2 欄 × 4 列：標題（樓層名稱＋面積檢討；多棟分棟時前綴棟別，樣板名也帶棟別如「A棟屋突層面積檢討」）→ 屋突面積（算式：室內樓地板面積）→ 允建屋突面積（算式：屋突允建面積）→ 檢討（算式：屋突檢討式）。
- 多棟且「各棟檢討屋突面積」或連棟透天：逐棟逐屋突層各一張；一般多棟合併檢討：用各棟總計的屋突層。各格已綁該層。舊版（正式版之前的開發版）生成的「樓層打開」屋突樣板會被列為 `stale`。

## 建蔽率檢討（`coverage`，樣板名「建蔽率檢討」，表格標題「建築面積檢討」，全案一張）

- 單一使用分區：兩欄，基地面積 → 扣除列（保留地／道路退縮地／鄰房侵佔／騎樓各 > 0 才列；騎樓地需 > 0 且「建蔽率計算時騎樓地從基地母數扣除」為真）→ 使用面積（純面積 token）→ 法定建蔽率 → 設計建築面積 → 建蔽率檢討（設計建蔽率計算式＋檢討式）。
- 多個使用分區：3 欄模板，col1 為陣列「土地資訊表-列出使用分區」（欄位排成列、分區排成欄、陣列自帶總計欄）；陣列列＝項目／基地面積／扣除列／使用面積（計算式）／允建建築面積（計算式）；其後全案列：法定建蔽率（不同使用分區計算式）／設計建築面積／建蔽率檢討。放到圖面後請使用者目視確認分區欄。

## 基地概要（`site_overview`，樣板名「基地概要」，全案一張，兩欄無合併）

- 基本資料：基地地號（專案資訊有基地位置就綁 token，否則佔位符）／使用分區／起造人（同上）／層棟戶數（幢棟層戶）／基地面積。
- 扣除列：保留地／道路退縮地／道路退縮地(計入法空)／鄰房侵占／騎樓／騎樓地，> 0 才列（騎樓地另需扣除設定）。
- 規定值 vs 設計值：其它面積(使用面積)（未扣除版計算式）／使用面積(建蔽率用)（有任一扣除項才列，已扣除版計算式）／建蔽率／容積率（允建）／允建建築面積／法定空地面積／設計建築面積／設計建蔽率／總樓地板面積／允建容積樓地板面積／設計容積樓地板面積／設計容積率。
- 工程造價三列：綁專案的建物工程造價計算式／雜項工作物造價計算式／總工程造價計算式；單價未設定時顯示空白並在 `notes` 提醒。
- 法規檢討 7 列（依建表當下數值挑分支寫成固定句，`placeholders` 會列出需人工處理者）：停車空間（總樓地板面積 < 500m² 免設，否則留法定車位佔位）／建築物污水處理設施（固定句，圖號佔位）／無障礙（戶數 < 10 免設，否則提示另做無障礙檢討表）／衛生設備（固定句）／地質鑽探（四層以下、非供公眾、設計建築面積 < 600m² 免鑽探，否則佔位）／防空避難（專案未設防空避難室＝免設，否則綁法定面積）／雨水滯洪（未勾需設置且基地 < 300m² 且都市計畫內＝免設，否則佔位）。條文門檻與地方自治條例請使用者複核。
