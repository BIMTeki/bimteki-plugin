# 建照審查表 —— 逐項檢討內容規格（第十八～二十七項）

固定 10 列。左欄為法規條文（**逐字照抄，不改字**）；右欄「檢討內容」依優先序組出：
**能綁自動文字就綁 → 否則標準樣板句（帶入本案實際值或「非…故免檢討」）→ 外部無法得知者留佔位符**。

- 右欄多以「檢討：…符合規定。~ok」收尾（沿用來源慣例；使用者不要「~ok」時整批拿掉）。
- 下方 `autotext 比對關鍵字` 僅為在 `get_project_autotext_catalog` 回傳中比對 `display` 名稱的線索；找不到對應 token 時，改用本案實際值（純文字）或佔位符。
- 佔位符慣例：文號 `◯◯◯字第◯◯◯◯◯號`、日期 `○○○年○○月○○日`、圖號 `A0-○`、案名 `（○○○案名）`。

## 自動文字對應（已於實際專案驗證）

綁定前先 `get_project_autotext_catalog`，建議一次取這幾個分類即可涵蓋本表所需：
`siteOverview,buildingOverview,coverage,volumeCheck`。再以下表的 **display 名稱**在回傳中比對取 `token`。

| 用途 | display 名稱（比對用） | 所在分類 |
|---|---|---|
| 使用分區 | `文字：使用分區` | siteOverview（基地概要） |
| 都市計畫名稱 | `都市計畫名稱` | siteOverview |
| 面前道路 | `面前道路（合併）` | siteOverview |
| 建蔽率規定值 | `比率：基準建蔽率` | coverage（建蔽率相關） |
| 建蔽率本案設計 | `比率：設計建蔽率` | coverage |
| 容積率規定值 | `比率：允建容積率` | volumeCheck（容積檢討→容積率相關→允建） |
| 容積率本案設計 | `比率：設計容積率` | volumeCheck（→設計） |

**重要規則**：
- **token 是各專案專屬的雜湊值（形如 `${TJL$…}`），會因專案而異；一律用 display 名稱比對後取用，絕不硬編碼上面任何 token。**
- **建蔽率規定值用「基準」、容積率規定值用「允建」**（此為不對稱）：容積率常有獎勵容積，設計值要跟「允建（基準＋獎勵）」比，故規定值取 `比率：允建容積率`；建蔽率通常無獎勵、且目錄僅有「基準／設計」，故規定值取 `比率：基準建蔽率`。若專案無 `比率：允建容積率`，才退回 `比率：基準容積率`。

## 大標題（Row 0）

兩行，跨 2 欄合併，**粗體、靠左、縮減字寬**（`charwidth: 1`；設縮減字寬會自動取消換行，兩行仍以單一 `\n` 手動斷行、彼此不空行）：

```
建造執照及雜項執照依建築法第三十四條第三項規定應由主管建築機關審查規定項目，
建造執照及雜項執照規定項目審查表中之查核項目
```

## 第十八項（套繪圖）

- **左欄**：`第十八項：套繪圖查核結果基地無違反規定重複建築使用`
- **來源**：標準樣板句，通常無需專案資料。
- **右欄**：`經查核本案基地無違反規定重複建築使用，符合規定。~ok`

## 第十九項（畸零地）

- **左欄**：`第十九項：基地符合畸零地使用規則規定。`
- **需要的資料**：面前道路寬度、基地最小寬度、基地最小深度、畸零地檢討圖圖號。
- **autotext**：面前道路 → `面前道路（合併）`（綁）。基地最小寬度／深度**目錄無對應**，留佔位符；圖號亦留佔位符。
- **右欄範本**：
  `檢討：面前道路為 ${面前道路（合併）} 計畫道路，且基地最小寬度 ◯◯＞3.5公尺，最小深度 ◯◯＞14公尺，詳畸零地檢討圖 A0-○ 符合規定。~ok`
- **註**：`3.5`／`14` 為畸零地使用規則門檻值，屬固定文字，不是佔位符；比較符號方向依實際值判斷。

## 第二十項（禁限建）

- **左欄**：`第二十項：基地符合禁限建規定。`
- **來源**：標準樣板句（**預設假設**；BIMTeki 無法判定是否位於軍事禁限建範圍）。
- **右欄**：`檢討：本案非位於軍事禁限建範圍，故免檢討。~ok`
- **註**：若基地確位於禁限建範圍，須改寫，回報時提醒使用者確認。

## 第二十一項（地質敏感區）— 外部文件

- **左欄**：`第二十一項：建築基地全部或一部位於地質敏感區內且無基地地質調查及地質安全評估結果報告經其他目的事業主管機關審查通過之證明檔者，其基地地質調查及地質安全評估結果報告。`
- **需要的資料**：是否位於地質敏感區、技師公會函之日期與文號 —— **皆為外部資訊，BIMTeki 無法得知，留佔位符**。
- **右欄範本**：
  `檢討：本案位於地下水補注地質敏感區，檢附社團法人土木技師公會○○○年○○月○○日(◯◯◯)中土結發字第◯◯◯-◯◯號函及核定本，詳建築基地地質調查及地質安全評估報告書。符合規定。~ok`
- **註**：若本案不在地質敏感區，可改為免檢討句 —— 由使用者確認。

## 第二十二項（農業區）

- **左欄**：`第二十二項：農業區內申請建築時其申請人身分符合規定。`
- **來源**：標準樣板句；可用使用分區交叉判斷（分區非農業區 → 免檢討句）。
- **右欄**：`檢討：本案非農業區內申請建築，故免檢討。`

## 第二十三項（容積率／建蔽率／層數／高度）— 重點 autotext

- **左欄**：`第二十三項：容積率、建蔽率、建築物層數或建築物高度規定值。`
- **需要的資料**：規定建蔽率、設計建蔽率、規定容積率、設計容積率、高度檢討圖圖號。
- **autotext（依上方對應表綁定，全部應綁）**：
  - 建蔽率規定值 → `比率：基準建蔽率`
  - 建蔽率本案設計 → `比率：設計建蔽率`
  - 容積率規定值 → **`比率：允建容積率`**（非「基準容積率」；見上方不對稱規則）
  - 容積率本案設計 → `比率：設計容積率`
- **右欄範本**（原圖中的小表以文字列呈現，格內用單一 `\n` 手動斷行、`newline: 1`；`${…}` 處放對應 autotext segment）：
  ```
  檢討：
  建蔽率　規定值 ${比率：基準建蔽率}　本案設計 ${比率：設計建蔽率}
  容積率　規定值 ${比率：允建容積率}　本案設計 ${比率：設計容積率}
  建築物高度規定值詳高度檢討 A0-○ 檢討圖，符合規定。~ok
  ```
- **註**：高度檢討圖圖號留佔位符 `A0-○`。無對應 autotext 時才填本案實際百分比（純文字）。不使用巢狀子表。

## 第二十四項（都市計畫／區域計畫用途）

- **左欄**：`第二十四項：都市計畫或區域計劃土地使用管制用途。`
- **需要的資料**：都市計畫名稱（autotext）；都計函之日期、文號（**外部，佔位符**）。
- **autotext**：都市計畫名稱 → `都市計畫名稱`（綁；本案可能空白，填了會自動帶出）。
- **右欄範本**（案名用 autotext 取代，不用佔位符）：
  `檢討：本案位於都市計劃地區，依○○○年○○月○○日府都計字第◯◯◯◯◯◯◯號函「${都市計畫名稱}」檢討，符合規定。~ok`

## 第二十五項（附條件項目）

- **左欄**：`第二十五項：都市計畫書或非都市土地開發許可計畫書附條件項目規定。`
- **來源**：標準樣板句。
- **右欄**：`檢討：依規定辦理。~ok`

## 第二十六項（建築物用途）— autotext

- **左欄**：`第二十六項：建築物用途。`
- **需要的資料**：使用分區（autotext）、建築物用途組別（如 H2 集合住宅）。
- **autotext**：使用分區 → `文字：使用分區`（綁）。**用途組別目錄無專屬欄位**；若專案「建築使用用途」已設定可帶入純文字，未設定則留佔位符 `◯◯◯（用途組別）`。
- **右欄範本**：
  `檢討：本案位於 ${文字：使用分區}，用途 ◯◯◯（用途組別）使用，符合規定。~ok`

## 第二十七項（直轄市、縣市政府規定審查項目）— 外部文件

- **左欄**：`第二十七項：直轄市、縣(市)政府規定之審查項目。`
- **需要的資料**：地方政府排水／污水相關函之主管機關、日期、文號 —— **外部，佔位符**。
- **右欄範本**：
  `檢討：本案位屬「用戶排水設備（預設用戶）」範圍，依（○○○主管機關）○○○年○○月○○日◯◯◯字第◯◯◯◯◯◯◯◯◯號函辦理，於基地內設置污水處理設施、切換裝置、自設陰井，符合規定。~ok`
- **註**：此項內容高度依地方規定與個案而定，樣板僅供起手，請使用者依實際情形調整（甚至整段替換）。
