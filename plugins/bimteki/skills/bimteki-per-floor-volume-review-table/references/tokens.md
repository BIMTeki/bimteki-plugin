# 各層容積檢討表 — display → token 對照（storyArea 分類）

值欄用**「算式：」**系列 token（會回傳含公式的字串，例「193.25*10%=20.36m²」）；
判 0 值用對應的**「面積：」**系列 token（回傳純數值）。標題用「樓層名稱」「棟別」。

這些是 BIMTeki 內建 storyArea 自動文字，實測在兩個不同專案 token 值相同（穩定），
`scripts/build_volume_table.py` 已內建同一份預設。**仍建議**用
`get_project_autotext_catalog(category="storyArea")` 依 display 比對確認；有出入時把該案實際 token
放進 config 的 `tokens` 覆寫，切勿硬編。
