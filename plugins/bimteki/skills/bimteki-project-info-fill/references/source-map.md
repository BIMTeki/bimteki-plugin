# 資料來源對照：欄位 → 資料夾文件

事務所專案資料夾多採 A～Z 分類（A_土地資料.公文.建築線、E_建築.設計圖說…）。下表是各資料項的**典型落點**；實際檔名依案而異，找不到就用 Glob 在對應分類夾內搜關鍵字（如 `謄本`、`土管`、`概要表`、`地下水補注`）。政府 PDF 常為掃描或文字層亂碼，逐字抄函號/日期時用視覺方式讀頁面。

| 資料項 | 典型落點（分類夾 → 檔名關鍵字） | 備註 |
|---|---|---|
| 基地地號、地籍、地價 | `A_土地資料…\03.謄本.套繪.土地資訊\1_謄本\` → `…謄本.pdf`（取最新日期那份） | 唯讀欄位，不寫回；地價供宜居/回饋參考 |
| 使用分區 | `A_…\03.謄本…\2_土地使用分區\` → `土地使用分區.pdf`、`住X之X(建蔽,容積).JPG` | 唯讀欄位；JPG 檔名常含法定建蔽/容積（如 `(50,140)`） |
| 都市計畫名稱、發布日期文號 | `A_…\02.都市計畫書…\1_都市計畫書\` → `…大土管…公告.pdf`（檔名常含發布日期，如 `1040722`） | 名稱→內建 `urban_plan_name`；發布日期/函號→自訂義參數（逐字） |
| 細部計畫名稱 | 同上都市計畫書夾；`M_細部計畫設計調整\` | 自訂義參數 |
| 土地使用分區管制要點（土管） | `A_…\02.都市計畫書…\1_都市計畫書\` → `單元X土管.pdf`／`.docx`（docx 文字層較好抄） | 逐條屬 landuse-review-table skill；本 skill 只取名稱/函號 |
| 地質敏感區（地下水補注/斷層/山坡地） | `A_…\03.謄本…\3_其他土地調查\` → `位於地下水補注敏感區.pdf`、`不位於山坡地.pdf`、`…斷層距離查詢.jpg` | 自訂義參數 `地質敏感地區`；技師公會函號另存 |
| 環境敏感（軍事禁限建、防火間隔） | `A_…\03.謄本…\3_其他土地調查\` → `…軍事禁限建….jpg`、`位於整體性防火間隔.jpg`；說明 `E_…\B-書類文件\00_建照\軍方…說明.docx` | 自訂義參數 |
| 建蔽率/容積率（法定與設計）、建築物用途組別、高度/簷高、開挖率、幢棟層戶 | `E_建築.設計圖說\B-書類文件\00_建照\` → `概要表.pdf`（取最新修訂） | 設計建蔽/容積/樓層/戶數=唯讀；用途組別→`usage_classes`；高度/簷高/開挖率→內建可寫；法定建蔽/容積→自訂義參數（外部依據） |
| 面前道路 | `A_…\04.測量圖.建築線\2_建築線\` → 建築線指定/免指定公告 | 內建 `front_roads` |
| 停車位數 | `E_…\B-書類文件\00_建照\` → `停車及升降設備附表.pdf` | 通常唯讀/由模型；如需留存數字可存自訂義參數 |
| 起造人、代表人、統編、地址 | `X_起造人所有權人相關資料\`；`C_業主往來資料\` | 起造人→內建 `owner`；其餘視需要存自訂義參數 |
| 各類技師公會簽證/函號 | `E_…\B-書類文件\00_建照\` → `簽證表.pdf`；建築師公會掛號 xlsx | 逐字函號→自訂義參數，抓不到留空 |
| 綠建築 / 宜居回饋 | `E_…\B-書類文件\00_建照\綠建築\`、`…\宜居\` → 報告書、回饋金試算表.pdf | 宜居回饋金→自訂義參數 |
| 建照號、發照日、變更設計函號 | `Y_執照存查\`；`E_…\B-書類文件\`（各次變更設計夾） | 自訂義參數；逐字 |

## 使用原則

- **逐字照抄**函號、日期、名稱、地號；不要推算或潤飾。
- **抓不到→標「待人工確認」**，不臆測。
- 讀 docx/xlsx 用對應處理方式；掃描 PDF 用視覺讀取，別信亂碼文字層。
- 二進位 CAD（.dwg/.pln/.bpn）不要開；需要的數值改從概要表等 PDF 取。
- 開始擷取前，先用 `get_project_core_snapshot` 看哪些欄位已有值，避免重工與覆蓋正確值。
