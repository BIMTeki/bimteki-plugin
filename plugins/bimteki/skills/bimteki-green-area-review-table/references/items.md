# 綠化面積檢討表 —— 逐列規格

左欄標籤用**本案土管的用詞**（基準是實設空地就寫「實設空地面積」、是法定空地就寫「法定空地面積」）。右欄組法優先序：**複合「算式：／計算式：」token（同時含公式與結果，且已依專案綠化參數算好）＞ 多個數值 token 自組算式 ＞ 佔位符**。

比對前先確認本案須做綠化檢討（都計內／有土管或特殊條例），並讀本案土管綠化條文取得**基準（實設空地 or 法定空地）、應綠化比率、綠化困難認定、喬木密度**。再 `get_project_autotext_catalog(category="green")`，以下表的 **display 名稱** 在回傳中比對取 `token`。**token 是各專案專屬的雜湊值，一律用 display 名稱比對後取用，絕不硬編碼下列任何 token 字串本身**——下列「顯示名稱候選」只是搜尋線索，實際專案 catalog 回傳名稱可能略有出入，找不到就依規則退回下一優先序，不要臆測硬湊。

## 綠化面積 BIMTeki 類別對照

BIMTeki 的「綠化面積」類別（見 `bimteki-lawname-index` 綠化面積章節）：

| 用途 | 請照空間名稱 | 索引 |
|---|---|---|
| 實設綠化面積 | 設計綠化面積 | 121 |
| 綠化有困難面積 | 無法綠化面積 | 122 |
| 綠化自訂參數（比率/密度等） | 綠化自訂參數1/2/3 | 123 / 124 / 125 |

> 應綠化比率、喬木每單位面積株數等規定值通常存為專案綠化參數（對應綠化自訂參數 123~125），BIMTeki 的複合算式 token 會據此算好。**這些規定值依本案土管而定，各土管不同**；建表前以土管核對。

## Row 1｜實設空地／法定空地（綠化基準面積，固定顯示）

- **標籤**：依土管基準寫「實設空地面積」或「法定空地面積」（**基準由土管決定，二擇一**）。
- **顯示名稱候選**：`green` 分類中「面積：實設空地」「面積：法定空地」「面積：空地」，或複合「算式：實設空地面積」。
- 綠化面積計算的基準（分母來源）；固定列，一律顯示。

## Row 2｜綠化面積（設計/實設綠化面積，固定顯示）

- **標籤**：「綠化面積」或「設計綠化面積／實設綠化面積」。
- **顯示名稱候選**：`green` 中「面積：設計綠化面積」（索引 121）。
- 本案實際留設的綠化面積（比對應綠化面積用）。

---

## Row 3｜綠化有困難面積（條件顯示）

- **標籤**：「綠化有困難面積」（土管用詞或作「無法綠化面積」）。
- **顯示名稱候選**：`green` 中「面積：無法綠化面積」（索引 122），或複合「算式：無法綠化面積」。
- **條件**：取 `get_project_green_info` 的 `areas.unable_green_area.value`（或 `evaluate_autotext_values(category="green")`；**不可用 `evaluate_story_autotext_values`，它只涵蓋 storyArea**）判值 **> 0 才顯示**；= 0（本案無綠化困難部位）預設略過，應綠化面積直接以基準×比率計。
- 綠化困難的認定範圍（車道、無頂蓋停車、必要設施等）**依土管條文**，不同土管不同。

---

## Row 4｜應綠化面積（固定顯示）

- **標籤**：「應綠化面積」。
- **顯示名稱候選（優先）**：`green` 中複合 token「算式：應設綠化面積」「計算式：應綠化面積」——本身即 `（基準空地－綠化困難面積）×應綠化比率＝應綠化面積` 的公式字串，且**已依專案綠化參數（比率）算好**，整格綁定即可。
- **找不到複合 token**：自組算式，操作數皆用 autotext，比率無 token 才用土管讀到的比率當文字常數：
  ```
  （{基準空地} － {無法綠化面積}）× ◯◯％ ＝ {面積：應設綠化面積}
  ```
  只在綠化困難列顯示時才串入「－{無法綠化面積}」。若「應綠化面積」結果本身也無 token，結果段落改文字佔位符 `（請依左式計算後填入）`，不要自己算出數字寫死。
- **強烈建議優先綁複合 token**：比率隨土管/專案設定變動，交給 BIMTeki 算式 token 最不易錯。

---

## Row 5｜喬木數量檢討（固定顯示）

- **標籤**：「喬木數量檢討」。
- **顯示名稱候選（優先）**：`green` 中複合 token「算式：喬木檢討式」「計算式：喬木數量」——本身即 `綠化面積／◯◯㎡＝應植喬木◯株，實植◯株，符合規定` 的公式＋結論字串，整格綁定即可。
- **找不到複合 token**：自組，操作數用 autotext（喬木密度無 token 才用土管常數）：
  ```
  {綠化面積} ／ ◯◯㎡ ＝ 應植喬木 ◯ 株，實植 ◯ 株
  ```
  「應植」「實植」若無 token，退回佔位符，不要自行算出株數寫死。
- 可與「綠化面積檢討（實設≧應綠化 結論）」合併於同格逐行呈現（見 SKILL.md 儲存格寫法的多行範例）；若土管另要求列出檢討結論，用複合「算式：綠化面積檢討式」token。
