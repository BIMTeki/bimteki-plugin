## 兩版都要的注意

- 面積 token 只渲染純數字 → 補「m²」；計算式 token 已完整（含 =／m²／%）→ 不補。
- 單分區使用面積用 `面積：使用面積(建蔽率用)總計`＋m²（計算式版在單分區壞成 0.00m²）；多分區使用面積用計算式欄位。
- 絕不寫死數字；扣除項依 >0 條件顯示；騎樓地另需扣除設定。
