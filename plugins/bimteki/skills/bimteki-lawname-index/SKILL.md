# BIMTeki 請照空間名稱索引表

本 skill 提供 BIMTeki Zone 的 GDL 參數 `lawName` 的索引值。
**使用規則：分隔線項目（如主要空間分隔線、次要空間分隔線等）不可作為 lawName 值填入，應跳過。**

## 如何使用

修改區域的 lawName 時，從下表找到對應名稱的索引值，填入 `modify_bimteki_zones` 的 `lawName` 參數。
