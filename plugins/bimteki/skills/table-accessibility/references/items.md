## 逐條檢討組法

| 條 | 條文主旨（照抄以現行為準） | 右欄檢討組法 |
|---|---|---|
| 第167條 | 無障礙設施設置義務與但書（獨棟同一住宅單元、公寓大廈專有部分、基地未達150㎡或每層未達100㎡等免設情形） | 樣板句：「本案為新建建築物，依規定辦理設置無障礙設施。」 |
| 第167-1條 | 居室出入口及無障礙廁所、浴室、昇降設備、停車空間、樓梯間須以無障礙通路連通 | 樣板句：「依規定設置無障礙通路。」 |
| 第167-2條 | 直達樓梯至少一座為無障礙樓梯 | 樣板句：「依規定設置無障礙樓梯。」 |
| 第167-3條 | 應設衛生設備者（除 H-2 住宅/集合住宅外）之無障礙廁所設置樓層規定 | 綁**用途組別** autotext ＋樣板句：「本案一層、二層、二夾層為 G-2 辦公室，於第一層設置無障礙廁所。」（樓層/用途依本案調整） |
| 第167-4條 | 設有共用浴室者，每幢至少一處無障礙浴室 | 樣板句：「本案未設共用浴室，故不適用。」（預設；若本案有共用浴室須改寫） |
| 第167-5條 | 設有固定座席席位者之輪椅觀眾席位數量規定 | 樣板句：「本案未設固定座椅席位，故不適用。」（預設） |
| 第167-6條 | 停車空間無障礙車位設置；H-2/集合住宅停車超過 50 位者之加設規定 | 綁**汽車停車位數** autotext ＋樣板句：「本案汽車車位設 〔車位數〕 輛，應設無障礙汽車車位 1 輛，本案設置 2 輛。」（應設/實設數依本案填） |
| 第167-7條 | 使用類組 B-4（旅館等）客房數 16 間以上之無障礙客房規定 | 樣板句：「本案非屬 B-4 組，故不適用。」（預設） |

## 待手填/需確認清單（回報時列出）

- 第167-3條：無障礙廁所實際設置樓層與用途（依本案）。
- 第167-6條：應設 / 實設無障礙車位數（若 autotext 未提供應設數，需人工確認換算）。
- 第167-4/167-5/167-7條：屬「未設…故不適用」預設假設，若與本案實情不符請使用者修正。
